# BRIGHTHOMES CONSTRUCTION SERVICE

> Building Dreams, Constructing Reality.

BRIGHTHOMES is a construction and real-estate services platform comprising an independently deployable Django REST API, React website, and Expo mobile application.

## Applications

- `backend/` — Django 5 REST API and Django Admin content-management foundation.
- `website/` — React, TypeScript, Vite public website.
- `mobile/` — Expo, React Native, TypeScript mobile application.

## Getting started

Each application has its own setup instructions and environment example. Read [docs/architecture.md](docs/architecture.md) before running the project.

Phase 1 establishes the foundation only; portfolio content and business workflows are deliberately deferred.
